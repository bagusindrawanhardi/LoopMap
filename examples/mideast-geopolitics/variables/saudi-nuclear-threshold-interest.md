# Variable: Saudi Nuclear Threshold Interest

- unit: Proximity to nuclear latency (years from threshold decision to functional deterrent, inverse scale)
- related_loops: L-02

## Definition

Saudi Arabia's proximity to nuclear weapons latency — the degree to which it has built the technical, institutional, financial, and political infrastructure that would allow rapid weaponization if the political decision were made. Higher variable value = closer to threshold (fewer years to deterrent capability).

## Unit

Inverse of years-to-threshold (so higher = more advanced latency): estimated current value = "5–10 years to minimal deterrent" = moderate threshold proximity.

## Related Loops

L-02 (Nuclear Proliferation Cascade)

## MBS Threshold Statement

Prince Mohammed bin Salman, March 2023 (FOX News): "If Iran gets a nuclear weapon, we will get one too." This is the clearest statement of conditional nuclear intent by any Arab leader since Libya's Gaddafi.
